# Hit & Miss Indicators

## Links

Source code: https://gitlab.com/MorleyDev/openmw_hitormissindicators

## Requirements

OpenMW 0.49+

## Installation

* Place in Data Files directory or equivalent via OpenMW Data Directories
* Enable HitAndMissIndicators.omwscripts in OpenMW Launcher

## Compatibility

Whilst nothing should break, any mod that alters the hit chance calculations or adds extra lua script affects may result in an incorrect percentage being shown on the Miss indicator
