========================================================================================================================
Patch for Purists v5.0.6 patch notes [Dcember 16th, 2025]
========================================================================================================================

- Fixed an issue where the door to the final Dagoth Ur chamber would not open after the first encounter by removing the DagothUrCreature1 script edit.
- Removed StartCombat Player from Vampire_<clan> scripts and restored the original short fightset so vampires attack on sight instead of rushing the tomb entrance.
- Fixed the cursed Ancient Silver Dagger being replaced by a non-enchanted version.
- Restored the missing enchantment on the Hair Shirt of Saint Aralor.
- Fixed a script issue that failed to remove the _x Goldbrand variant, preventing players from ending up with both Goldbrand and Eltonbrand.
- Improved topic filtering for Pemenie’s quest, fixing issues that prevented confronting her.
- Fixed a misplaced voiced Imperial greeting for Bosmer (Disposition 70).
- Fixed a missing wall near the top of the stairs in Rethan Manor.
- Properly applied the previously non-functional fix for Com_Chest_11_k01.
- Corrected an inverted line in the ColonySeler script that prevented Seler from spawning during East Company Empire: Bar Brawl (CO_7).
- Removed partial “Fix those bastard rope fences” files; installing the full mod is now recommended instead.
- Removed the stone ramp in Urshilaku, Laterus Burial, preventing main quest progression without Levitation or excessive jumping.

PfP Fixes

- Optional modules were merged into the main patch for convenience and to avoid the mod limit.
